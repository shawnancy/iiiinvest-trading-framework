# iiiinvest Trading Framework（电鱼哥交易思路）

从 [@iiiinvest](https://x.com/iiiinvest) 公开帖里整理出的学习用技能，覆盖大约 2026 年 9 月中旬到 11 月 6 日的长文和喊单帖。

这不是交易信号，也不是投资建议。文中盈亏数字都是原作者自称，未核对成交单。

## 别人怎么调用

这是一份标准的 Cursor / Grok Bot `SKILL.md`。

1. 把本仓库的 `SKILL.md` 复制到你的技能目录，例如：
   - 项目内：`.cursor/skills/iiiinvest-trading-framework/SKILL.md`
   - 或你平时放技能的位置
2. 在对话里用 `@iiiinvest Trading Framework` 或说明「按电鱼哥这套思路总结」来调用。
3. 助手应按技能里的硬规矩工作：只讲他的逻辑和自称结果，不给买卖建议，不算假装精确的喊单胜率，不编造他没写过的宏观事件。

完整框架、五个共性和案例对照都在 [SKILL.md](./SKILL.md)。

## 这份材料在讲什么

可复用的不是某一次多空，而是他反复出现的决策顺序：

1. 先问盘面在交易哪一个宏观主题，再问这个主题是不是已被定价。
2. 先分清这是反弹，还是趋势反转。
3. 价格结构是行动开关：破走，不破拿。
4. 用相对强弱和「谁被套住」来选标的。
5. 认错时用破位或止损结束旧单，不靠加仓硬扛。

他这一阶段实际用到的宏观时钟，主要是美国中期选举、美联储路径、通胀数据、中东与油价、大科技财报和 AI 监管预期，而不是中国的两会。
